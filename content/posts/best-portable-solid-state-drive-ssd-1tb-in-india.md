## Which portable drive should you pick?

- **For a phone:** the SanDisk Creator Phone SSD.
- **For a laptop or general use:** the Samsung T7.
- **For travel and rough handling:** the SanDisk 2TB Rugged.
- **For cheap bulk backup:** the Seagate One Touch, keeping in mind it is a slower hard drive.

## What to check before buying

- **Interface.** Full speed needs a USB 3.2 Gen 2 port and a cable that supports it.
- **Capacity.** Pick the size you need now plus some room. Prices rise sharply with size, so check the live price.
- **Durability.** Only some listings state drop protection. Read the listing if you carry the drive often.
- **Warranty.** The four drives list 3 to 5 years. Check the seller's terms.
- **SSD or HDD.** An SSD is faster and tougher. An HDD is cheaper per terabyte.
