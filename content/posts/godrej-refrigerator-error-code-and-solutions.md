### Godrej Refrigerator Error Code and Solution - Common Problems Explained

### Error Code E1 - Temperature Sensor Malfunction

If your Godrej refrigerator displays Error Code E1, it indicates a problem with the temperature sensor. This sensor is responsible for monitoring the internal temperature of the refrigerator and sending the data to the control board. When it malfunctions, the refrigerator may not maintain the correct temperature, leading to potential food spoilage.

### Solution

: Unplug the refrigerator from the power source and wait for a few minutes. Plug it back in, and if the error persists, consider contacting a qualified technician to replace the faulty temperature sensor.

### Error Code E2 - Defrost Heater Failure

Error Code E2 signals an issue with the defrost heater in your Godrej refrigerator. The defrost heater is responsible for melting frost that accumulates on the evaporator coils. If it fails, frost will build up, hindering the cooling process and potentially leading to temperature fluctuations.

### Solution

: To address this problem, unplug the refrigerator and remove any food items from the freezer. Allow the ice to melt naturally or use a hairdryer to expedite the process (maintain a safe distance from the refrigerator). Once the ice is melted, plug the refrigerator back in. If the error persists, you may need to replace the defrost heater with the help of a professional.

### Error Code E3 - Fan Motor Malfunction

When you see Error Code E3, it indicates an issue with the fan motor in your Godrej refrigerator. The fan motor is crucial for circulating air throughout the appliance, ensuring even cooling and preventing temperature imbalances.

### Solution

: Begin by unplugging the refrigerator and checking for any obstructions around the fan blades. Clear any debris or ice buildup that might hinder the fan's movement. Afterward, plug the refrigerator back in, and if the error persists, the fan motor may need replacement. Contact a certified technician to assist you with this repair.

### Error Code E4 - Communication Error Between Control Board and Display

Error Code E4 suggests a communication error between the control board and the display panel of your Godrej refrigerator. This miscommunication can result in inaccurate readings and irregular functioning of the refrigerator.

### Solution

: Firstly, perform a hard reset by unplugging the refrigerator from the power source for a few minutes. Then, plug it back in and check if the error is resolved. If not, the control board or display panel may require replacement. It's best to seek help from a professional technician to diagnose and fix the problem accurately.

### Error Code E5 - Door Switch Fault

Error Code E5 indicates an issue with the door switch in your Godrej refrigerator. The door switch is responsible for detecting whether the refrigerator door is open or closed. If it fails, the refrigerator might not function correctly, and you may face cooling problems.

### Solution

: Check if the door is closing properly without any obstruction. Clean the area around the door switch and ensure it's making proper contact when the door is closed. If the error persists, the door switch may need replacement. Contact a technician with experience in Godrej refrigerators to assist you with the repair.

### Error Code E6 - Evaporator Fan Motor Error

Error Code E6 signals a problem with the evaporator fan motor, which is responsible for circulating air over the evaporator coils. When this fan motor malfunctions, it can lead to cooling issues and temperature imbalances.

### Solution

: Start by unplugging the refrigerator and examining the fan motor for any visible damage or obstructions. Clear any debris and check if the fan blades move freely. Plug the refrigerator back in, and if the error continues, consider seeking help from a professional technician to replace the evaporator fan motor.

### Error Code E7 - Ambient Temperature Sensor Failure

Error Code E7 indicates a malfunction with the ambient temperature sensor. This sensor monitors the external temperature around the refrigerator and provides vital information to the control board for optimal cooling performance.

### Solution

: Unplug the refrigerator and wait for a few minutes before plugging it back in. If the error persists, there might be an issue with the ambient temperature sensor. Contact a qualified technician to diagnose and resolve the problem.

### Error Code E8 - Condenser Fan Motor Problem

Error Code E8 points to a problem with the condenser fan motor, which is responsible for expelling heat from the refrigerator's condenser coils. If this fan motor fails, the refrigerator's cooling efficiency may be affected.

### Solution

: Unplug the refrigerator and check for any obstructions around the condenser fan motor. Clean the area thoroughly and ensure the fan blades can rotate freely. Plug the refrigerator back in, and if the error remains, you may need to replace the condenser fan motor with the help of a technician.

### Error Code E9 - Defrost Sensor Issue

Error Code E9 indicates a problem with the defrost sensor in your Godrej refrigerator. This sensor monitors the temperature of the evaporator coils during defrost cycles and sends data to the control board.

### Solution

: Unplug the refrigerator and remove any frost or ice buildup around the defrost sensor. Clean the area and ensure the sensor is making proper contact with the coils. Plug the refrigerator back in, and if the error persists, consider contacting a qualified technician to inspect and replace the defrost sensor if necessary.

### Error Code E10 - Communication Error Between Main Control and Display

When you encounter Error Code E10, it suggests a communication issue between the main control board and the display panel. This miscommunication can lead to incorrect readings and improper functioning of the refrigerator.

### Solution

If not, the main control board or display panel may need replacement. Seek assistance from a professional technician to accurately diagnose and fix the problem.

### Error Code E11 - Inverter Board Fault

Error Code E11 points to a problem with the inverter board in your Godrej refrigerator. The inverter board controls the compressor's speed, allowing the refrigerator to adjust its cooling capacity based on the internal temperature.

### Solution

: Unplug the refrigerator and check for any visible damage or burnt components on the inverter board. If any damage is found, the inverter board will need replacement. Contact a qualified technician to replace the faulty inverter board and restore your refrigerator's proper functionality.

### Error Code E12 - Compressor Overload Protection

Error Code E12 indicates that the compressor of your Godrej refrigerator has entered overload protection mode. This can happen when the compressor faces excessive strain or when there's an issue with the starting components.

### Solution

: Unplug the refrigerator and wait for approximately 15 to 20 minutes to allow the compressor to cool down. Afterward, plug the refrigerator back in, and if the error persists, there might be a problem with the compressor or its starting components. Contact a professional technician to diagnose and fix the issue.
