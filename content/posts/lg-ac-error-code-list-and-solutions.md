LG is a well-known brand when it comes to home appliances, including air conditioners. Like any other air conditioner, LG AC units can encounter issues that may require troubleshooting. One way to identify these issues is through error codes displayed on the AC unit's screen. In this blog, we will discuss the most common [LG AC error codes](/lg-ac-error-code-list-and-solutions/) and their solutions.

## Error Codes

### CH 01: Indoor Unit Return Air Sensor Error

This error code indicates a fault in the indoor unit return air sensor. The solution is to check the sensor and ensure it is properly connected or replace it if necessary.

### CH 02: Indoor Pipe Sensor Error

The CH 02 error code indicates a fault in the indoor pipe sensor. The solution is to check the sensor and ensure it is properly connected or replace it if necessary.

### CH 03: Outdoor Unit Discharge Pipe Sensor Error

This error code indicates a fault in the outdoor unit discharge pipe sensor. The solution is to check the sensor and ensure it is properly connected or replace it if necessary.

### CH 04: Outdoor Unit Suction Pipe Sensor Error

The CH 04 error code indicates a fault in the outdoor unit suction pipe sensor. The solution is to check the sensor and ensure it is properly connected or replace it if necessary.

### CH 05: Communication Error between Indoor and Outdoor Units

This error code indicates a communication error between the indoor and outdoor units of the AC system. The solution is to check the wiring connections between the two units and ensure they are properly connected.

### CH 06: Compressor Discharge Temperature Sensor Error

This error code indicates a fault in the compressor discharge temperature sensor. The solution is to check the sensor and ensure it is properly connected or replace it if necessary.

### CH 07: Current Sensor Error

The CH 07 error code indicates a fault in the current sensor. The solution is to check the sensor and ensure it is properly connected or replace it if necessary.

### CH 08: Excessive High Pressure Protection

The CH 08 error code indicates that the AC unit has detected an excessive high-pressure protection error. This could be due to a clogged air filter or a refrigerant leak. The solution is to clean or replace the air filter and have a professional check for refrigerant leaks and repair them if necessary.

### CH 09: Excessive Low Pressure Protection

The CH 09 error code indicates that the AC unit has detected an excessive low-pressure protection error. This could be due to a refrigerant leak or a faulty compressor. The solution is to have a professional check for refrigerant leaks and repair them if necessary, or replace the compressor if it is faulty.

### CH 10: Indoor Unit Error

This error code indicates a fault in the indoor unit. The solution is to check the indoor unit and ensure it is properly connected or replace it if necessary.

### FAQ : LG AC Error Code

LG Air Conditioner (AC) Error Code FAQ. If you're experiencing an error code on your LG air conditioner, refer to this FAQ for information on what it means and what you can do to resolve it.

### Q: What is an error code on an LG AC?

A: An error code on an LG AC is a series of letters and/or numbers that indicate a specific problem with the unit.

### Q: How do I find out what error code my LG AC is displaying?

A: You can find out what error code your LG AC is displaying by referring to the user manual or by doing a quick internet search with the model number and error code.

### Q: What are some common LG AC error codes?

A: Some common LG AC error codes include CH 01, CH 02, CH 05, CH 24, and CH 67.

### Q: What does the CH 01 error code mean?

A: The CH 01 error code on an LG AC indicates a communication error between the indoor unit and the outdoor unit. This may be due to faulty wiring or a malfunctioning control board.

### Q: What does the CH 02 error code mean?

A: The CH 02 error code on an LG AC indicates an indoor pipe sensor error. This may be due to a faulty sensor or a malfunctioning control board.

### Q: What does the CH 05 error code mean?

A: The CH 05 error code on an LG AC indicates an outdoor unit malfunction. This may be due to a faulty motor or compressor.

### Q: What does the CH 24 error code mean?

A: The CH 24 error code on an LG AC indicates a malfunction in the indoor unit's air intake or outlet. This may be due to a blocked air filter or a clogged air vent.

### Q: What does the CH 67 error code mean?

A: The CH 67 error code on an LG AC indicates an abnormal communication between the outdoor unit's compressor and fan. This may be due to a faulty control board or a malfunctioning sensor.

### Q: What should I do if I encounter an error code on my LG AC?

A: If you encounter an error code on your LG AC, refer to the user manual for troubleshooting steps or contact a professional HVAC technician for assistance. In some cases, resetting the unit or performing routine maintenance may resolve the issue.
