## Error Codes

**Error Code E1**

This error code indicates that the room temperature sensor is faulty. The solution is to replace the room temperature sensor, which is typically located on the indoor unit. You can consult the user manual or contact a certified Whirlpool technician for assistance with sensor replacement.

**Error Code E2**

This error code indicates that the evaporator sensor is faulty. The evaporator sensor measures the temperature of the indoor coil. The solution is to replace the evaporator sensor, which is usually located on the indoor unit.

**Error Code E3**

This error code indicates that the outdoor ambient temperature sensor is faulty. The outdoor ambient temperature sensor measures the temperature of the outdoor air. The solution is to replace the outdoor ambient temperature sensor, which is typically located on the outdoor unit.

**Error Code E4**

This error code indicates that the condenser temperature sensor is faulty. The condenser temperature sensor measures the temperature of the outdoor coil. The solution is to replace the condenser temperature sensor, which is usually located on the outdoor unit.

**Error Code E5**

This error code indicates that the communication between the indoor and outdoor units is faulty. The communication between the indoor and outdoor units is essential for proper operation. The solution is to check the communication wiring and connections between the indoor and outdoor units for any loose or damaged wires, and ensure proper connections are made.

**Error Code E6**

This error code indicates that the indoor unit's fan motor is faulty. The fan motor is responsible for circulating air in the indoor unit. The solution is to replace the indoor unit's fan motor, which is typically located inside the indoor unit.

**Error Code E7**

This error code indicates that the outdoor unit's fan motor is faulty. The fan motor in the outdoor unit is responsible for dissipating heat from the outdoor coil. The solution is to replace the outdoor unit's fan motor, which is usually located on the outdoor unit.

**Error Code E8**

This error code indicates that the indoor unit's water tank is full. Some Whirlpool AC units come with a built-in water tank that collects condensed water from the indoor coil. When the water tank is full, it can trigger the E8 error code. The solution is to drain the water tank by removing the drain plug or following the manufacturer's instructions.

**Error Code E9**

This error code indicates that the indoor unit's air filter is dirty. A dirty air filter can affect the performance and efficiency of the AC unit. The solution is to clean or replace the air filter, which is typically located on the front panel of the indoor unit.

**Error Code F1**

This error code indicates that the refrigerant pressure is too low. Low refrigerant pressure can affect the cooling performance of the AC unit. The solution is to check for refrigerant leaks and add refrigerant as needed. Refrigerant work should be performed by a certified technician in compliance with local regulations.

**Error Code F2**

This error code indicates that the refrigerant pressure is too high. High refrigerant pressure can also affect the cooling performance of the AC unit. The solution is to check for obstructions in the refrigerant lines or a faulty expansion valve, and take appropriate measures to rectify the issue.

**Error Code F3**

This error code indicates that the compressor is overheating. The compressor is the heart of the AC unit, and overheating can lead to system failure. Solution: Check the wiring connections between the outdoor unit's temperature sensor and the main control board. Replace the temperature sensor if it's damaged.

**Error Code F4**

This error code indicates that the outdoor unit's coil temperature is too high. The solution is to check for obstructions in the air intake or a faulty outdoor fan motor.

**Error Code F5**

This error code indicates that the indoor unit's coil temperature is too high. The solution is to check for obstructions in the air intake or a faulty indoor fan motor.

**Error Code F6**

This error code indicates a refrigerant leakage. The solution is to check for leaks and repair or replace the affected parts.


### Troubleshooting Tips for Whirlpool AC Issues

In addition to the specific error codes mentioned above, here are some general troubleshooting tips to address common Whirlpool AC issues:

- Ensure the AC unit is receiving an adequate power supply.
- Check and clean the air filters regularly for proper airflow.
- Keep the area around the indoor and outdoor units free from obstructions.
- Maintain a suitable temperature setting to avoid overworking the AC unit.
- Schedule regular maintenance checks with a professional technician to keep your AC in optimal condition.

It is important to note that some error codes may require professional repair or assistance. If you are unable to troubleshoot or fix the issue yourself, it is recommended to contact a certified Whirlpool technician for assistance. Regular maintenance and cleaning of your AC unit can also help prevent errors and ensure optimal performance.

### Frequently Asked Questions (FAQ) - Whirlpool AC Error Code

### Q: What should I do if my Whirlpool AC displays an error code?

A: First, refer to the user manual or online resources to identify the error code and its meaning. Then, try to troubleshoot the issue based on the suggested solutions provided. If the issue persists, contact a certified technician or customer service representative.

### Q: Can I reset the error code on my Whirlpool AC?

A: Yes, you can reset the error code by turning off the AC and unplugging it from the power source for a few minutes. Then, plug it back in and turn it on again. However, resetting the error code will not solve the underlying issue causing the error.

### Q: What are some common causes of Whirlpool AC error codes?

A: Some common causes include low refrigerant levels, dirty filters, faulty sensors or thermostats, malfunctioning fan motors or compressors, and electrical issues.

### Q: Can I fix Whirlpool AC error codes myself?

A: It depends on the severity and complexity of the issue causing the error code. Simple issues like dirty filters or low refrigerant levels can often be fixed by the user, while more complicated issues may require the expertise of a certified technician.

### Q: How can I prevent Whirlpool AC error codes?

A: Regular maintenance, such as cleaning or replacing filters and scheduling professional tune-ups, can help prevent issues that can lead to error codes. Additionally, avoiding overuse or misuse of the AC and ensuring proper installation can also help prevent issues.

### Q: How often should I clean the air filters of my Whirlpool AC?

To maintain optimal performance, it is recommended to clean the air filters of your Whirlpool AC every two to four weeks or as specified in the user manual.

### Q: Can I repair a refrigerant leak in my Whirlpool AC myself?

Repairing a refrigerant leak requires specialized knowledge and equipment. It is recommended to seek assistance from a professional technician to ensure the proper repair and handling of refrigerant.

### Q: What is the importance of regular maintenance for Whirlpool AC units?

Regular maintenance helps identify and address potential issues before they escalate, ensuring the efficient and reliable performance of your Whirlpool AC. It also prolongs the lifespan of the unit.

### Q: How can I schedule a maintenance check for my Whirlpool AC?

You can contact Whirlpool customer support or reach out to authorized service centers to schedule a maintenance check for your Whirlpool AC unit.
