## Commer Voltas AC Error Codes

1. E1 - This error code indicates a communication problem between the indoor and outdoor units. This can be caused by loose or damaged wiring connections. The solution is to check the wiring connections and ensure they are properly connected. If the wiring is damaged, it should be repaired or replaced.
2. E2 - This error code indicates a problem with the room temperature sensor. The sensor may be faulty or disconnected. The solution is to check the sensor and replace it if necessary.
3. E3 - This error code indicates a problem with the outdoor unit's fan motor. The fan motor may be faulty or obstructed. The solution is to check the motor and remove any obstructions. If the motor is faulty, it should be replaced.
4. E4 - This error code indicates a problem with the indoor unit's fan motor. The fan motor may be faulty or obstructed. The solution is to check the motor and remove any obstructions. If the motor is faulty, it should be replaced.
5. E5 - This error code indicates a problem with the temperature sensor on the indoor unit's evaporator coil. The sensor may be faulty or disconnected. The solution is to check the sensor and replace it if necessary.
6. E6 - This error code indicates a problem with the outdoor unit's refrigerant pressure sensor. The sensor may be faulty or disconnected. The solution is to check the sensor and replace it if necessary.
7. E7 - This error code indicates a problem with the outdoor unit's condenser coil temperature sensor. The sensor may be faulty or disconnected. The solution is to check the sensor and replace it if necessary.
8. E8 - This error code indicates a problem with the indoor unit's discharge air temperature sensor. The sensor may be faulty or disconnected. The solution is to check the sensor and replace it if necessary.
